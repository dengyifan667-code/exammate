# ExamMate

ExamMate 是一个开源的智能期末考试助手。学生上传个人课表和学校发布的考试安排 PDF 后，应用会在浏览器本地识别课程、核对班号，并生成个人考试日程。

在线体验：<https://exammate-mvp.syrupydandelion.chatgpt.site>

## 核心功能

- 双文件上传：个人课表 + 学校考试安排。
- 支持 JPG、PNG、PDF、CSV 和 TXT 课表。
- 网格课表图片按星期分栏 OCR，减少跨列串字。
- 根据“课程名称 + 括号内班号”精确匹配考试。
- OCR 结果必须通过学校 PDF 课程目录校验，低置信结果不会冒充已确认课程。
- 支持一条考试记录覆盖多个教学班。
- 识别学校 PDF 中的 “No Final Examinations” 清单。
- 保留原始 PDF 页码，方便人工核对。
- 文件仅在浏览器本地处理，不上传服务器。

## 本地运行

项目没有构建步骤，也不需要安装依赖。

1. 下载或克隆仓库。
2. 直接打开 `dist/index.html`。
3. 点击“使用示例数据”体验完整流程，或上传自己的文件。

如需避免浏览器对本地文件的限制，也可以用任意静态文件服务器托管 `dist/`。

## 推荐文件格式

个人课表 CSV / TXT：

```text
课程编号,课程名称（班级号）
MATH1201,高等数学（2）
```

学校考试安排 CSV / TXT：

```text
课程编号,课程名称（班级号）,考试日期,考试时间,考试地点
```

PDF 应尽量使用可复制文字的版本。JPG / PNG 课表需要联网加载浏览器端 OCR 模型。

## 隐私

ExamMate 是纯前端应用。用户选择的课表和考试文件不会上传到 ExamMate 服务器。PDF 解析和图片 OCR 都在用户浏览器中完成。

## 当前限制

- 不同学校的课表和 PDF 结构差异很大，解析规则仍需持续扩展。
- 扫描版考试安排 PDF 暂不支持 OCR。
- Word、Excel、账号系统、云端保存和日历导出尚未加入。
- 所有考试信息都应在考试前与学校原文件再次核对。

## 项目结构

```text
dist/
  index.html   页面结构
  styles.css  水绿色视觉样式
  app.js      文件解析、OCR、课程匹配和日程逻辑
```
